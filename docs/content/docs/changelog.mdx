## 0.2.2 / 0.2.5

Made the libraries lighter:

- Dropped **Zod** from `@scribblesvg/core` in favor of hand-rolled validation
- Removed **lucide-react** from `@scribblesvg/react-utils`; toolbar icons are in-house SVGs

## 0.2.x

- Core document model with scribble-style rendering (Rough.js)
- React `DiagramCanvas` editor and `DiagramRenderer` read-only view
- Icon catalog via `iconId` + consumer `icons` array
- Color presets for the renderer
- Fumadocs documentation site (`docs/`)
